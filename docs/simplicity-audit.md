# Simplicity audit (#247)

Owner decision 2026-10-08: many simple things are built in a convoluted way. This audit covers every module in `taskq/`,
the contracts and the docs. For each mechanism it asks one question: does the core idea need it? The core idea is a
board-driven queue under [R1–R12](../taskq/contracts/principles.md). The answer is one of three verdicts: delete,
simplify, or keep. Line numbers are from `origin/main` at `f696271`. Estimates count deleted lines minus the
replacement's lines. Nothing in this task changes code.

## Owner decisions the follow-ups need

1. **GitHub board.** R1 bans a mirror, but the Projects v2 board is a copy of the labels: GitHub cannot show labels as columns. Keep the one-way copy (row 15), or drop it and use the label-filtered issue list as the board?
2. **Tick sender.** Keep only the launchd `tick --act --wake` timer, or only the in-session CronCreate tick? One kind of sender removes the prompt-version and re-arm machinery (row 12).
3. **`[runtimes.<name>]` executors.** Does any project configure one? If not, delete them (row 18).
4. **`stable` update channel.** Does any install pin `[update] ref = "stable"`? If not, drop the signed-tag path (row 19).
5. **`cleanup_helpers`.** Does csgo still need its own `workspace_gc` and `host_gentle`? If not, use the built-in tools only (row 20).
6. **External PM routes.** Are DOT or Hermes PMs still in use? Row 13 and the `--json` shape of row 16 depend on the answer.

The follow-ups below take the lazy default when an answer is missing, and they name the default they took.

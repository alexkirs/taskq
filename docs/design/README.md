## Как читать макеты

- Меню: структура и взаимодействия. Значки внутри него — предыдущая отрисовка; не копировать их как финальные.
- Иконки: финальная геометрия и состояния — только `icon-studies.html`, поведение — M1/M5/M6.
- Пауза сводки: прежние цифры/бары серые; поверх та же компактная q с Ⅱ, по центру обеих осей.
- HTML — дизайн-материалы, не готовые нативные компоненты. Данные демонстрационные; ссылки issues реальные.
- Проверка модели не доказывает отрисовку или работу сервиса. Границы — в `verification.md`.
